# Pharmacy System Operational Runbooks

This directory contains operational runbooks for common tasks and procedures in the pharmacy management system.

## Available Runbooks

- [System Startup](./system_startup.md) - Starting and stopping the pharmacy system
- [Database Backup](./database_backup.md) - Backup and restore procedures
- [Performance Monitoring](./performance_monitoring.md) - Monitoring system performance
- [Error Handling](./error_handling.md) - Troubleshooting common errors
- [User Management](./user_management.md) - Managing users and permissions
- [Stock Management](./stock_management.md) - Managing inventory and stock
- [Insurance Claims](./insurance_claims.md) - Processing insurance claims
- [Disaster Recovery](./disaster_recovery.md) - Disaster recovery procedures

## How to Use Runbooks

Each runbook contains step-by-step instructions for performing specific operational tasks. Follow the instructions carefully and document any deviations.
